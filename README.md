# SlimeQuest
Slime Quest Es un Plataformero en el cual encarnaras a un personaje el cual fue fusionado con un slime adquiriendo habilidades sobre humanas, este para poder separa nuevamente sus cuerpos se embarca en una aventura la cual consiste en subir una montaña esto debido que al llegar a la sima habrá algo que lo puede ayudar a su objetivo
